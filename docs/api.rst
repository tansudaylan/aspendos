API reference
=============

Aspendos re-exports the following functions from Chalcedon for older imports.
New applications should import them from ``chalcedon``.

.. py:function:: aspendos.retr_mcutfrommscl(fracacutasca)

	Return the dimensionless enclosed mass fraction for a positive cutoff-to-scale-radius ratio.

.. py:function:: aspendos.retr_mcut(defs, asca, acut, adislens, mdencrit)

	Return the truncated halo mass from the profile and lensing-distance inputs.

The maintained `Chalcedon documentation <https://chalcedon.readthedocs.io/>`_
describes the canonical lensing API and its physical assumptions.
